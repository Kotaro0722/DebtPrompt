# テストケース一覧: `main_message.get_register_pattern`

## 対象関数

```python
async def get_register_pattern(message,guild=None):
    ids=await get_member_list(message,guild)
    pattern = r"(?:"+"|".join(re.escape(f"<@{id}>") for id in ids)+r")\s*-?[0-9]+円(?:\s+.*|$)"
    return pattern
```

- `get_member_list` の結果から、借金登録メッセージ（例：`<@123> 500円 詳細`）を判定するための正規表現パターン文字列を組み立てる
- メンバー数によって `(?:...)` 内の `|` 区切りの選択肢数が変わる

## MECEの切り口

- **A. メンバーが0人**（`get_member_list` が空リストを返す）
- **B. メンバーが1人**
- **C. メンバーが複数人**
- **D. 生成されたパターンが実際の入力に対して正しく機能するか**（パターン生成のロジックとは別軸の確認）
